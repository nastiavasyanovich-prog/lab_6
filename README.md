# Хрестики-нолики (проєкт 6, варіант 14)

Дві сопрограми грають у хрестики-нолики на полі n×n.

## Запуск
tictactoe.exe            - n і k вводяться з клавіатури
tictactoe.exe input.txt  - n і k читаються з файлу

## Формат вхідного файлу
Два цілі числа через пробіл:
n k
- n - розмір поля (від 1 до 20)
- k - скільки знаків у ряд потрібно для перемоги (від 1 до n)

Приклад: 3 3
